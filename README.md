# NexaOS AI 🚀

AI-powered productivity workspace built with React, FastAPI and Groq AI.

## Features

- 📝 Create and manage tasks
- ✅ Complete / undo tasks
- 🗑️ Delete tasks
- 📊 Total, completed and pending task statistics
- 🤖 AI productivity assistant
- 📋 AI-powered daily planning
- 🎯 AI task prioritization
- ⚡ Productivity recommendations
- 💬 Natural-language AI interaction
- ➕ Add tasks using AI
- ✅ Complete tasks using AI
- 🗑️ Delete tasks using AI
- 📱 Responsive productivity dashboard

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Python
- FastAPI
- Pydantic
- Uvicorn

### AI
- Groq API
- OpenAI GPT-OSS 120B
